# Проверки и ограничения версии 2.5

Версия 2.2 успешно собрана в GitHub Actions (run 42896087334). Пользователь подтвердил установку, передачу пульса Mi Band 6 и сохранение статистики после продления подписи.

В 2.3 добавлены: разбор FEE0-счётчика шагов выбранного браслета; отдельный частичный подсчёт шагов за активные интервалы; расширенная сводка GPS-пробежки, график пульса и километровые отрезки. Сбросы счётчика, паузы и пропуски не заполняются оценками. Приём шагов на конкретном физическом браслете ещё требуется проверить.

Локальные проверки: 60 тестов основных модулей, расчёты новых показателей, браузерные регрессии GPS/GPX/архива здоровья/пульса, 9 проверок состава пакета. Новые XCTest выполняются на macOS при сборке. Шаги iPhone и браслета хранятся раздельно. Сон, SpO2, стресс и память тренировок Mi Band через broadcast не синхронизируются.

Личная программа автоматически исключается при упаковке публичного проекта. Обновление существующей установки выполняется с прежним Apple ID и идентификатором приложения; данные приложения не входят в публичный репозиторий.

Сборка 2.3: GitHub Actions run 43046215238, commit c5d64c1126c426de571a5106f47e9937db506cb3 — success. Архив iPhone собран; 28 модельных XCTest и проверка первого запуска/повторного открытия интерфейса прошли. Браузерная проверка нового экрана на настоящем приложении также прошла (7 тестов вместе с расчётами).

## Обновление 2.4

Тренировка с другом: отдельный таймер и заметка, посещение только после явного завершения, сохранение после перезапуска, удаление/отмена и резервная копия. Обычная программа и силовые результаты не подменяются. Обновлены расположение действий, формы, типографика, карточки и эскиз маршрута.

Локально: 73 модульных теста; браузерные сценарии обычной тренировки и режима с другом; функциональная проверка на настольном WebKit с узким экраном; визуальная проверка 45 состояний при ширине 320, 390 и 430 px без ошибок страницы и геометрии. Это не проверка версии 2.4 на физическом iPhone. Сборка 2.4 на macOS подтверждена ниже.

## Обновление 2.5

Добавлены однократные локальные исправления существующей программы без сброса истории и пользовательских тренировок. Личный пакет исправлений не публикуется: при публичной упаковке PROGRAM_UPDATE равен null. В скачанный unsigned IPA пакет добавляется локально перед личной подписью. После применения последующие ручные изменения не сбрасываются. Исторические снимки упражнений не изменяются.

Поля даты и источника архива здоровья размещены в отдельных строках для нативного поля даты iOS. Локально прошли 76 тестов модулей и браузерная проверка применения исправлений/ширин 320, 390, 430. Сборка 2.5 ожидается.
